Automated job-search pipeline (how I apply to jobs)Sistema automático de búsqueda de empleo (así busco trabajo)

ProblemProblemaTailoring a CV and cover letter for every offer took ~45 minutes, and new offers were easy to miss.Adaptar CV y carta a cada oferta llevaba unos 45 minutos y era fácil perderse ofertas nuevas.
What I builtQué construíA daily scheduled pipeline that reads the Airbus careers portal and 7 remote-job sources, scores each offer against my profile, and generates a 1-page ATS CV and a cover letter with an LLM — using only facts from a single "master profile", with an automatic check that flags any figure or tool not in it.Un proceso diario programado que lee el portal de empleo de Airbus y 7 fuentes de teletrabajo, puntúa cada oferta frente a mi perfil y genera un CV ATS de 1 página y una carta con un LLM — usando solo hechos de un "perfil maestro", con un control que marca cualquier cifra o herramienta que no esté en él.
ResultResultado~2,700 offers screened per day → a ready-to-use dashboard with job link, PDFs and copy-paste answers. About 5 minutes per application instead of 45. Running cost: free tier LLM.~2.700 ofertas revisadas al día → un panel listo con enlace, PDFs y respuestas para copiar. Unos 5 minutos por candidatura en vez de 45. Coste: capa gratuita del LLM.
Design choicesDecisionesNo invented content, human-in-the-loop submission, public APIs only, resilient to API errors.Nada inventado, el envío final lo hace una persona, solo APIs públicas, tolerante a errores de las APIs.
Python · Gemini API · Playwright (HTML → PDF) · Workday & job-board APIs · Windows Task Scheduler
